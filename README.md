# ZenState downloads

Official installers and automatic update files for ZenState.

[Download the latest version](https://github.com/Everything-Design/ZenState-Releases/releases/latest)

- macOS Apple Silicon: arm64.dmg
- macOS Intel: x64.dmg
- Windows x64: Setup.exe
- Linux x64: AppImage or amd64.deb

Installers, update manifests, blockmaps and checksums are published under Releases. This repository contains no application source history. ZenState is proprietary software for the Everything Flow team.

Existing users: install v5.9.3 or newer to keep receiving automatic updates after the source repository becomes private. Your time records and settings stay on your device.
